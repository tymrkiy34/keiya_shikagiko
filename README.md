# 技工所管理(納品書・請求書・技工物管理)

歯科技工所向けの業務管理ソフトです。`index.html` をブラウザで開くだけで動きます(インストール・サーバー不要)。
データはブラウザ内(localStorage)に保存されます。**「設定・バックアップ」から定期的にJSONを保存してください。**

## 機能
- 料金表(区分・単価・税区分:10% / 8% / 非課税)
- 取引先(歯科医院)管理:締め日・掛率・支払条件
- 技工物管理:受付〜製作中〜完成〜納品済、納期超過の強調表示、患者名・歯式・シェード、修理/再製(無償)、作業票印刷、CSV出力
- 納品書:完成した技工物から医院ごとに自動作成・印刷/PDF保存
- 請求書:締め日までの納品書を一括集計、税率ごとの内訳(インボイス対応の記載)、入金管理(分割入金・残高)
- ホーム:納期超過/本日納期/未請求額/未入金残高
- バックアップ/復元

## 注意
- 初期の料金表はサンプルです。実際の料金に書き換えてください。
- 保険技工物は非課税、自費は課税が一般的ですが、税区分は税理士にご確認ください。
